Запечатанный нектар — интерактивная книга

Что внутри:
- Вся книга: 17 глав, 123 урока, ≈ 25 часов озвученного текста.
- Текст книги почти целиком (без сносок), в каждом уроке иллюстрированные сцены и карты.
- В иллюстрациях нет изображений людей — только пейзажи, архитектура, карты, предметы и орнамент.

Как открыть:
1. Распакуйте архив целиком.
2. Откройте index.html в Microsoft Edge (лучшие голоса «Microsoft ... Online (Natural)»).
3. Выберите урок и нажмите «Начать».

Управление:
- Справа — текст книги, текущее предложение подсвечивается.
  Клик по любому предложению — перейти к нему.
- Пробел — пауза, ← / → — сцены, ⚙ — голос и скорость.
- В конце каждого урока — 5 вопросов.
Прогресс сохраняется в браузере.

## Телефоны и планшеты
- На узких экранах включается мобильный вид: иллюстрация сверху (в альбомной ориентации — слева), текст книги ниже обычным размером шрифта, крупные кнопки внизу.
- Текст можно листать пальцем — через несколько секунд он вернётся к читаемой фразе. Нажатие на фразу — озвучка с этого места.
- Озвучка — голос устройства. iPhone/iPad: Настройки → Универсальный доступ → Устный контент → Голоса → Русский → «Милена (улучшенный)». Android: «Синтезатор речи Google» с русским пакетом.
- Чтобы открыть с телефона, папку нужно выложить на любой хостинг (GitHub Pages, Netlify и т. п.) — из zip-архива на телефоне страницы не запускаются.
